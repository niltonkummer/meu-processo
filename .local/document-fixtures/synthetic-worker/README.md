# Fixtures sintéticos do worker

Esta pasta aceita somente PDFs sintéticos usados na validação local controlada.
O nome de cada arquivo deve ser o identificador UUID externo do documento,
seguido de `.pdf`.

Nunca coloque aqui documentos reais, nomes, CPF/CNPJ, números CNJ, e-mails ou
URLs. Todos os PDFs desta pasta são ignorados pelo Git.
